Config name meaning (28 configs: 1 baseline + 27 GoE grid)
All runnable configs live in this folder: 02052026_uneven_cifar100/*.yaml.
Run with: --config-path configs/class --config-name 02052026_uneven_cifar100/baseline (etc).
run_test.py and run_test.sh use these config names.

Key configs (self-contained; no _archive or other defaults):
  1. baseline.yaml           — All params in file. MoE N8 only, no GNN.
  2. GoE-L2-H768-HeadNone.yaml — All params in file. MoE-GNN (GoE) with default L=2, H=768, Head=linear.
The other 26 GoE configs extend only GoE-L2-H768-HeadNone and override model.graph_num_layers, graph_hidden_dim, graph_head_layers.

baseline
  MoE N8 only, no GNN. Reference for all GoE runs.

GoE-L{1|2|3}-H{512|768|1024}-Head{None|512|512_256}
  L   = graph_num_layers:  1, 2, or 3     (default: 2)
  H   = graph_hidden_dim:  512, 768, or 1024   (default: 768 = d_model)
  Head= graph_head_layers: None (linear), [512], or [512, 256]   (default: None)

Examples:
  GoE-L2-H768-HeadNone       = key GoE config (2 layers, 768, linear head)
  GoE-L3-H512-Head512_256    = extends key; 3 layers, hidden 512, head [512, 256]
